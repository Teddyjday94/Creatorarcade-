# Demo pass (October 14, 2026)

Goal: get CreatorArcade running outside ChatGPT Sites and good enough to demo end to end.

## Functionality

- **Runs standalone.** Replaced `app/chatgpt-auth.ts` with `lib/auth.ts` (demo personas by default, Sites headers optional). Fresh databases bootstrap their schema automatically (`db/index.ts`).
- **Multi-role demo.** Persona sign-in page, persona switcher in the top bar and on `/play`, sign-out. The demo editor is a real persona, so the owner → editor → owner loop works.
- **Richer, resettable demo data.** Four challenges covering every stage, 17 entries, tasks in all four ClipCrew columns, comments, activity. `PUT /api/demo` resets only the caller's demo workspace.
- **Public viewer surfaces.** Results page, OBS overlay, results API, and challenge pages work signed out. Previously the overlay required sign-in, which made it unusable in OBS.
- **`/play` hub** for viewers: open challenges, recently wrapped ones, and "your entries" with status and placing.
- **Owner dashboard:** "Needs your attention" (entries to review, edits to review, winners to pick), recent activity feed, linked metrics.
- **Editor dashboard:** assigned / in progress / overdue, plus an up-next list.
- **Challenge page:** lifecycle stepper, summary cards (deadline countdown, entry count, viewer link), status tabs with counts, one-click Accept / Shortlist / Reject per entry, ClipCrew status per entry, private note preview, placing picker (1st/2nd/3rd selects instead of number fields), podium and overlay preview once results are live.
- **ClipCrew task page:** stage stepper, asset list, clearer next step, real names on comments, request-changes tucked behind a disclosure.
- People show as names everywhere (was "Editor 1", "Owner", raw ids).
- Forms clear after successful posts (comment box used to keep its text). Destructive actions confirm first.
- Branded viewer pages use the workspace accent color.

## Design

- Space Grotesk display type + Inter body via Google Fonts.
- Raised small text sizes (many labels were 8–10px).
- Status badges with dots and friendly labels (Live, Judging, Results live).
- Color-coded entry cards, live pulse chip, mobile shell with a slide-down menu.

## Tests

40 passing (37 original, demo test rewritten, 3 added for stage coverage, reset isolation, and the play hub).
Browser walkthrough covered all three personas through submit → shortlist → assign → edit → approve → rank → publish → overlay, plus new challenge from template, invite creation, and guest redemption.
